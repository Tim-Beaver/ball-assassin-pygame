This is a pygame top-down shooter where you control a circle and shoot squares which come wave after wave.

**WASD - movement
LMB (click or hold) - shoot
R - ultimate (when ready)
Aim with the mouse**

The game needs pygame 2.6.1 (for the `scale_by` function to work), random, math and schedule to run.
